# PdfPixel.Tiff

A TIFF image decoder for .NET covering classic TIFF and BigTIFF, strips and tiles, chunky and planar samples, and LZW, Deflate, PackBits, CCITT, JPEG and JPEG 2000 compression. Written in managed C# with no rendering dependencies.

Part of [PDF Pixel](https://github.com/zayg21-pixel/pdf-pixel). It comes in with the `PdfPixel` package; install it on its own only to decode TIFF files.

See [PdfPixel.Examples](https://github.com/zayg21-pixel/pdf-pixel/tree/main/PdfPixel.Examples) for runnable usage examples.
