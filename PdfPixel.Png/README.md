# PdfPixel.Png

A PNG image decoder and encoder for .NET covering every color type and bit depth, Adam7 interlacing and the chunks of the PNG specification, Third Edition. Written in managed C# with no rendering dependencies.

Part of [PDF Pixel](https://github.com/zayg21-pixel/pdf-pixel). It comes in with the `PdfPixel` package; install it on its own only to decode or encode PNG files.

See [PdfPixel.Examples](https://github.com/zayg21-pixel/pdf-pixel/tree/main/PdfPixel.Examples) for runnable usage examples.
