# PdfPixel.PdfPanel

A platform-independent PDF viewer core for .NET: page layout, scrolling and zooming, background page decoding, text selection, search and annotation popups. Built on `PdfPixel` and SkiaSharp; the host supplies the drawing surface and forwards input.

Part of [PDF Pixel](https://github.com/zayg21-pixel/pdf-pixel). Install it directly only to host the viewer on a UI framework of your own; for WPF, use `PdfPixel.PdfPanel.Wpf`, which brings this package in.

See [PdfPixel.Demo.Wpf](https://github.com/zayg21-pixel/pdf-pixel/tree/main/PdfPixel.Demo.Wpf) and [PdfPixel.Demo.Web](https://github.com/zayg21-pixel/pdf-pixel/tree/main/PdfPixel.Demo.Web) for hosting examples.
