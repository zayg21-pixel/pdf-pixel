# PdfPixel.Snap

Snap, the CPU rasterizer of PDF Pixel, designed for specification-compliant PDF rendering: draws recorded PDF page commands, transparency included, onto a `PdfSnapSurface` of its own or onto image samples you supply. Written in managed C#.

Part of [PDF Pixel](https://github.com/zayg21-pixel/pdf-pixel), where it renders page content for the viewer and the tools.

See [PdfPixel.Examples](https://github.com/zayg21-pixel/pdf-pixel/tree/main/PdfPixel.Examples) for runnable usage examples.
