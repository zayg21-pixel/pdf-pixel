# PdfPixel.Jbig2

A JBIG2 bi-level image decoder for .NET, written in managed C# with no rendering dependencies.

Part of [PDF Pixel](https://github.com/zayg21-pixel/pdf-pixel), where it decodes `JBIG2Decode` image streams. It comes in with the `PdfPixel` package; install it on its own only to decode JBIG2 data outside a PDF.

See [PdfPixel.Examples](https://github.com/zayg21-pixel/pdf-pixel/tree/main/PdfPixel.Examples) for runnable usage examples.
