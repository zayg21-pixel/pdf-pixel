# PdfPixel.PostScript

A PostScript tokenizer, expression compiler and evaluator for .NET, written in managed C# with no rendering dependencies.

Part of [PDF Pixel](https://github.com/zayg21-pixel/pdf-pixel), where it evaluates Type 4 (PostScript calculator) functions and Type 1 font programs. It comes in with the `PdfPixel` package; install it on its own only to evaluate PostScript outside a PDF.

See [PdfPixel.Examples](https://github.com/zayg21-pixel/pdf-pixel/tree/main/PdfPixel.Examples) for runnable usage examples.
