# PdfPixel

A native C# PDF library for .NET, designed for specification-compliant PDF rendering: parses documents and records their pages as commands, which `PdfPixel.Snap` rasterizes. No dependency on external PDF frameworks.

See [PdfPixel.Examples](https://github.com/zayg21-pixel/pdf-pixel/tree/main/PdfPixel.Examples) for runnable usage examples, or the [project README](https://github.com/zayg21-pixel/pdf-pixel) for the complete feature matrix.
