# PdfPixel

A native C# PDF rendering library for .NET, built around SkiaSharp. Renders PDF documents to raster output with full fidelity, with no dependency on external PDF frameworks.

See the [full documentation](https://github.com/zayg21-pixel/pdf-pixel/blob/main/docs/getting-started.md) for usage examples, or the [project README](https://github.com/zayg21-pixel/pdf-pixel) for the complete feature matrix.
