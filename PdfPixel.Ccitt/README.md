# PdfPixel.Ccitt

A CCITT Group 3 and Group 4 fax image decoder for .NET, written in managed C# with no rendering dependencies.

Part of [PDF Pixel](https://github.com/zayg21-pixel/pdf-pixel), where it decodes `CCITTFaxDecode` image streams. It comes in with the `PdfPixel` package; install it on its own only to decode CCITT data outside a PDF.

See [PdfPixel.Examples](https://github.com/zayg21-pixel/pdf-pixel/tree/main/PdfPixel.Examples) for runnable usage examples.
