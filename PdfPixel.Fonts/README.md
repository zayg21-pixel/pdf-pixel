# PdfPixel.Fonts

Font parsing and glyph outline extraction for .NET: CFF, Type 1, TrueType and OpenType (SFNT), plus the URW Core 35 fonts used as Standard 14 substitutes. Written in managed C# with no rendering dependencies.

Part of [PDF Pixel](https://github.com/zayg21-pixel/pdf-pixel), where it backs the PDF font handling. It comes in with the `PdfPixel` package; install it on its own only to read font programs outside a PDF.

See [PdfPixel.Examples](https://github.com/zayg21-pixel/pdf-pixel/tree/main/PdfPixel.Examples) for runnable usage examples.

Bundles the URW Core 35 fonts under the SIL Open Font License 1.1; see `notices/PdfPixel.Fonts.txt` in the package.
