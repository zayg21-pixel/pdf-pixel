# PdfPixel.Jpx

A JPEG 2000 image decoder for .NET covering the JP2 container and raw J2K codestreams. Written in managed C# with no rendering dependencies.

Part of [PDF Pixel](https://github.com/zayg21-pixel/pdf-pixel), where it decodes `JPXDecode` image streams. It comes in with the `PdfPixel` package; install it on its own only to decode JPEG 2000 data outside a PDF.

See [PdfPixel.Examples](https://github.com/zayg21-pixel/pdf-pixel/tree/main/PdfPixel.Examples) for runnable usage examples.
