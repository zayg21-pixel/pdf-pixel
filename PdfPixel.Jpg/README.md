# PdfPixel.Jpg

A JPEG image decoder for .NET covering baseline and progressive DCT frames, with ICC profile segment handling. Written in managed C# with no rendering dependencies.

Part of [PDF Pixel](https://github.com/zayg21-pixel/pdf-pixel), where it decodes `DCTDecode` image streams. It comes in with the `PdfPixel` package; install it on its own only to decode JPEG data outside a PDF.

See [PdfPixel.Examples](https://github.com/zayg21-pixel/pdf-pixel/tree/main/PdfPixel.Examples) for runnable usage examples.
