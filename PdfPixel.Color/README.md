# PdfPixel.Color

ICC color management for .NET: ICC v2 and v4 profile parsing, tone reproduction curves, CLUT pipelines and CMYK conversion. Written in managed C# with no rendering dependencies.

Part of [PDF Pixel](https://github.com/zayg21-pixel/pdf-pixel), where it backs the PDF color spaces. It comes in with the `PdfPixel` package; install it on its own only to apply ICC transforms outside a PDF.

See [PdfPixel.Examples](https://github.com/zayg21-pixel/pdf-pixel/tree/main/PdfPixel.Examples) for runnable usage examples.

Bundles a public-domain compact CMYK profile; see `notices/PdfPixel.Color.txt` in the package.
